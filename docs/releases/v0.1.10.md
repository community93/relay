# Relay 0.1.10

统一桌面工作区与交付文档的视觉细节，增强技术内容的可读性和运行对象的辨识。

- 页面标题、正文、辅助文字和按钮使用一致的尺寸与字重；调整导航、当前标签、表格和响应工具栏。
- 运行步骤直接显示方法、名称和地址；长地址省略，悬停查看完整内容；集合保留类型和可执行请求数。
- 文档进度、待完善和版本集中展示；概述有明确编辑焦点，添加草稿使用展开箭头，目录与字段表更易扫读。
- 交付预览和独立 HTML 共用改进的排版；目录、验证信息、表格、代码更清晰，方法颜色适配深色。
- 变量候选、当前变量与请求预览调整文字密度，维持实时值、敏感值遮罩及独立弹窗。
- 优化关闭、删除、搜索等图标控件的操作区；文档库悬停采用边框与阴影反馈。
- 修正空响应按钮文案、侧栏版本显示，以及文档概述边框导致的自适应高度问题。
