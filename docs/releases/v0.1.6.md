# Relay 0.1.6

本次更新完善了从接口调试到交付文档的连续操作：模块切换恢复编辑位置，文档聚焦当前接口，排序操作支持拖拽与撤销，请求旁可以直接查看环境变量解析结果。

## 交互与文档

- 返回集合、运行计划、文档或环境时，恢复上次编辑对象及滚动位置；分类标题保留独立总览入口。
- 正在查看的环境与实际生效的环境分别显示，“使用中”标签标记发送环境。
- 文档默认展开当前接口，其余显示名称、路径及状态；支持展开全部对照。
- 添加 cURL 区域可收起，接口目录切换直接打开对应接口。
- 文档保存状态反映真实写盘结果，失败时提供就地重试；连续保存按顺序提交。

## 排序与恢复

- 计划步骤、文档块及接口目录支持拖拽、插入线、边缘滚动和 Esc 取消。
- 支持 `Alt+↑/↓` 键盘排序。
- 集合和侧栏排序、计划步骤操作、文档块插入 / 删除 / 排序支持 `Ctrl+Z` 与 `Ctrl+Shift+Z`。
- 修复重复请求在计划步骤排序与撤销中的位置处理。

## 请求与实时流

- HTTP、SSE、WebSocket 在地址附近显示当前环境及缺失变量。
- 解析请求详情可固定展开，随编辑和环境变化刷新；WebSocket 展示握手详情。
- “上次发送”继续独立保留实际提交快照。
- SSE 连接期间锁定解码格式；清空显示保留当前连接累计统计。
- SSE / WebSocket 暂停滚动跟随时显示新消息数，点击恢复跟随。

## 视觉与布局

- 区分菜单与拖拽图标，扩大文档操作按钮的点击区域。
- 保留原字号档位，新增 125%、150%、200% 选项，并优化文档大字号布局。
- 重排使用简短位移动效，实时消息减少重复动画。
- 修复响应阅读位置恢复及协议切换时地址栏宽度跳动。
