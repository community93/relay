# Relay 0.1.8

变量查看改为独立弹窗，减少请求编辑区的展开内容和页面滚动。

- 点击请求地址下方的变量数量，打开“当前请求变量”弹窗。
- 弹窗只展示当前请求使用的变量、解析值与来源，保留实时刷新与缺失提示。
- 敏感值默认遮罩，可手动显示；HTTP、SSE 和 WebSocket 共用该入口。
- 多变量在弹窗内滚动，请求编辑区高度和已展开详情保持原状。
- 支持关闭按钮、点击遮罩及 Esc 关闭；关闭后焦点返回变量入口。

浏览器交互回归 45 / 45 通过，覆盖弹窗不改变编辑区高度、实时变量刷新、敏感值显隐和关闭后焦点恢复。

安装附件：`Relay_0.1.8_x64-setup.exe`，适用于 Windows 10 / 11 x64。
