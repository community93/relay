# Relay 0.1.13

修正动效样式覆盖和标签指示条边界，并统一验证实际渲染结果。

- 菜单、弹窗入场与关闭动效在一个样式文件中定义，删除重复和无调用规则。菜单为 140ms，弹窗入场为 180ms；标签和侧栏选择使用轻量淡入。
- 活动标签指示条留在水平滚动容器内，减少裁切与纵向溢出。
- 主按钮保持实色，悬停改变底色，键盘聚焦保留轮廓；移除底层残留的发光规则。
- 圆角按现有共享尺度保持一致；通过六套配色的明暗界面检查其实际效果。
- 界面、程序与安装包版本统一为 0.1.13。
