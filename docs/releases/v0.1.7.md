# Relay 0.1.7

优化请求地址下方的环境与变量信息栏，让请求编辑区的排版更加统一。

- 环境、变量信息与地址栏和参数区对齐，移除贴边布局及多余空隙。
- 环境与变量使用独立图标和细分隔线，移除含义不明确的绿色圆点。
- “查看解析请求”独立靠右，补充展开箭头、悬停和展开状态。
- 展开的请求详情统一左右边距。
- 长环境名和变量名省略显示，悬停查看完整内容；窄区域自动换行。
- HTTP、SSE、WebSocket 共用相同布局。
- 点击变量数量直接展开当前请求的变量表，显示解析值与来源；请求和环境变化时实时刷新，未使用的变量不列出。敏感值默认遮罩，可手动显示。

浏览器交互回归 44 / 44 通过，包含变量入口、实时值刷新和敏感值显隐；检查了 1000 / 1440 像素窗口下的标准、150%、200% 字号布局，以及解析详情的展开、收起和变量替换。历史完整回归结果见 0.1.6 测试报告。
