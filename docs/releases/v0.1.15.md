# Relay 0.1.15

新增 **AI 连接**：其他 AI 工具可以操作正在运行的 Relay 工作区，创建请求、配置响应检查、执行验证并编写交付文档。用户在应用内查看相同的请求、响应、检查证据和字段说明，再确认交付。

- 本地认证 API：默认关闭，随机端口，只监听本机；关闭后旧凭证失效。
- 支持集合、环境、HTTP/SSE/WS 请求、运行计划、文档与字段说明；cURL 通过现有解析器导入。
- HTTP 请求执行、文档批量验证、计划运行返回可查询和取消的任务；业务检查失败独立于网络成功。
- 更新已有内容需要匹配当前版本；拒绝覆盖未保存草稿或正在执行的请求。
- 真实验证生成时间戳、请求快照和响应样例；接口或环境变化后提示过期。AI 接口不能伪造验证或替用户确认交付。
- 提供通用 `relay-workflow` skill 和无第三方依赖的 Python 客户端，导出 Markdown / HTML / OpenAPI。
- 文档导出的cURL示例不再重复URL与Params中的同名查询参数；AI直接填写URL也生成查询字段。
- 修复发送后加入文档时，检查规则快照缺失导致已验证接口立即显示过期的问题。

本版本同时包含0.1.14阶段的表单检查、运行变量提取、OpenAPI3 JSON / HAR 导入。

AI 自动执行目前支持 HTTP；SSE/WS 可创建配置并在应用内调试。连接关闭阻止新命令，已经开始的执行可以在应用中查看或主动取消。详细步骤见 [AI 工作流](../ai-workflow.md)，命令格式见 [API 参考](../../skills/relay-workflow/references/api.md)。
